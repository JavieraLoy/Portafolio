## 🧠 Sobre el proyecto:

Este portafolio fue desarrollado como una aplicación SPA(Single Page Application) utilizando Vue 3, 
con el objetivo de presentar mis habilidades como desarrolladora frontend, incluyendo proyectos, tecnologías y formas de contacto.

El enfoque principal está en la creación de una interfaz moderna, interactiva y responsiva, aplicando buenas prácticas de desarrollo y diseño UI.

------------

## 🛠️ Tecnologías utilizadas:

• HTML5
• CSS3
• JavaScript(ES6)
• Vue 3
• Vue Router
• Bootstrap 5 + Metodología BEM
• Git & GitHub 

------------

## 🧩 Características:

• 🎨 Diseño moderno con estilo neón.
• 🧩 Arquitectura basada en componentes reutilizables.
• 🔁 Renderizado dinámico de proyectos desde JSON.
• 🌐 Navegación SPA con Vue Router.
• ⚙️ Configuración optimizada para GitHub Pages (BASE_URL).
• 👩‍💻 Sección "Sobre mí" personalizada.
• 📬 Botón de contacto directo (Gmail).
• 📄 Descarga de CV en PDF.
• 🖱️ Interacciones UI (hover, animaciones).

------------

## ⚙️ Instalación y uso:

1️⃣ Clonar el repositorio:

git clone 

2️⃣ Entrar al proyecto:

cd portafolio-vue

3️⃣ Instalar dependencias:

npm install

4️⃣ Ejecutar el servidor de desarrollo:

npm run dev

5️⃣ Abrir en navegador:

http://localhost:5173

🔗 Repositorio

Repositorio público:

-----------

📦 Build
npm run build

## 🚀 Deploy:

Este proyecto está desplegado en GitHub Pages, utilizando una rama dedicada para servir la versión de producción.

Se implementaron soluciones para:

• Manejo de rutas en entornos estáticos.
• Compatibilidad con Vue Router.
• Uso de import.meta.env.BASE_URL para assets.
